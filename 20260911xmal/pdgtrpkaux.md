# 副主委单位！洛阳妇幼儿童呼吸学科再获高度认可！

> 更新时间：2026-09-11 (UTC+8)

**好消息好消息**

**全国卫生健康系统先进工作者、**

**儿童呼吸内科主任代富力**

**获聘为河南省妇幼保健协会**

**儿科呼吸专委会副主任委员！！！**

5月24日，第二届黄河流域儿童健康学术会议-儿科呼吸专科联盟论坛在郑州召开，本次论坛由河南省妇幼保健协会、山东省妇幼保健协会等九家省级协会联合主办，旨在加强与黄河流域各省市儿科呼吸领域的交流与合作，共同推动儿科呼吸健康事业的发展。我院儿童呼吸内科主任代富力、副主任李永涛，急诊医学科主任路俊锋参加会议。代富力主任受邀对多个病例汇报进行了精彩的点评。

同日，河南省妇幼保健协会儿科呼吸专业委员会正式成立并成功举办第一届学术会议。河南省妇幼保健协会儿童呼吸专业委员会的成立，是河南省儿童呼吸健康事业发展的重要里程碑，更是推动区域医疗协同发展的重要契机。

我院儿童呼吸内科主任代富力获聘河南省妇幼保健协会儿科呼吸专委会副主任委员，副主任李永涛获聘常务委员，急诊医学科主任路俊锋、副主任医师李法涛获聘委员。这标志着我院在儿童呼吸领域的专业实力获得国家级认可，为区域儿科医疗协同发展注入强劲动力。我院儿童呼吸内科作为豫西地区唯一的儿童呼吸专科，将不负使命，为儿童的健康保驾护航。
**科室简介**

儿童呼吸学科作为洛阳市妇幼保健院的重要学科之一，2025年获批通过洛阳市重点专科，已完成了学科整合、亚专业细化等工作，形成了呼吸介入、感染、过敏、喘息性疾病、呼吸重症、慢性肺疾病、呼吸康复等多个亚专业互相促进、协同发展的崭新局面。

作为豫西地区唯一的儿童呼吸专科，在豫西地区乃至省内有较强的影响力，是洛阳市儿科呼吸学组组长单位、洛阳市医师协会儿科分会主委单位。设置儿童呼吸病诊疗中心（门诊）、儿童呼吸内科病区（一、二、三区）、儿童呼吸内镜中心。科室固定床位106张，年出院患儿4000余名，除常见的呼吸系统疾病以外，对于先天性支气管肺发育不良、吞咽功能障碍、先天性肌萎缩、先天免疫缺陷等特殊罕见病均有丰富的治疗经验。每年开展支气管镜诊疗术1000余例，门诊量每年1万余人次，长期建档随访哮喘及慢性肺疾病患儿每年300余名。

科室先后获得国家级青年文明号，河南省工人先锋号等荣誉称号。科主任代富力荣获全国卫生健康系统先进工作者、洛阳市优秀名医称号。

**儿童呼吸病诊疗中心开展有**：婴幼儿潮气肺功能检查、脉冲震荡肺功能检查、肺通气功能检查、支气管激发试验、支气管舒张试验、过敏原检测（包括体内与体外试验）、呼出气一氧化氮检测、脱敏治疗、过敏性疾病生物靶向治疗、肺康复治疗、穴位贴敷、雾化吸入治疗、鼻腔冲洗、无创吸痰等多项先进检查及治疗技术，建立儿童哮喘及慢性肺疾病随诊预约及随访档案管理机制，规范化诊治和管理哮喘及慢性肺疾病患儿。2018年被评为“中国儿童哮喘标准化门诊”，2025年又通过中国儿童哮喘标准化门诊的评审。呼吸内镜诊疗中心：有独立的呼吸内镜诊疗区域、先进的仪器设备和专业的儿童呼吸内镜技术诊疗团队，在豫西地区率先开展儿童支气管镜诊疗技术，如：可弯曲支气管镜检查、肺泡灌洗、呼吸道异物取出术、内生性异物取出术、经支气管镜激光治疗、经支气管镜喉软化声门上激光治疗成形术，经支气管镜气道狭窄球囊扩张术、硬质支气管镜介入技术等限制性四级手术，呼吸道异物一次性取出率100%。

2024年年底儿童呼吸内科通过福棠儿童医学发展研究中心“儿童呼吸学科规范化建设”项目的考评。2023年与广州市妇女儿童医疗中心签订了合作帮扶协议；2024年与山东省妇幼保健院孟晨教授签约，通过现场指导、带教查房等工作，共同建立了良好的合作关系。
